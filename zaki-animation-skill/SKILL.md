# Zaki Viral Animation

Make a short, vertical (9:16) animated video that hooks in the first second and keeps people watching to the end. Work in stages and get the user's OK before spending credits.

## 1. Understand the request
Ask (in one short message, only what is missing):
- Topic or story idea
- Style (3D cartoon, Pixar-like, clay, anime, 2D flat, realistic)
- Language of the voiceover and target length (default 30-45 seconds)

## 2. Write the script
- First line = ONE strong hook (a surprising fact, a question, or "Imagine...").
- Short sentences, one idea per sentence, 70-110 words for 30-45 seconds.
- End with a twist, a payoff, or a question that makes people comment.
Show the script and wait for approval.

## 3. Build the scene plan (no credits yet)
Split the script into 6-10 scenes. For each scene give:
- The line of voiceover it covers
- Shot: camera angle and movement (close-up, wide, slow push-in, orbit...)
- Image prompt: subject, action, setting, lighting, style keywords, "vertical 9:16"
- Motion prompt: what moves and how, 5 seconds
Keep one fixed "character sheet" line (look, colours, clothing) and paste it into every prompt so the character stays the same.
Show the plan as a numbered list and wait for approval. This step saves credits.

## 4. Generate
With the Higgsfield connector:
1. Generate the scene images first (one per scene). Show them; redo only the ones the user rejects.
2. Animate each approved image into a 5-second clip with its motion prompt.
3. If voice generation is available, generate the voiceover; otherwise give the user the final script to record.

## 5. Deliver
- List the clips in order with their timing, and give an edit plan: cut on every new sentence, add bold word-by-word captions, keep music very soft under the voice.
- Write a caption with the hook, 3 key points, a comment call-to-action, and 8-10 hashtags.

## Rules
- Never generate everything at once without approval; images before video.
- Keep characters and style consistent across scenes.
- Never copy real channels' characters or logos; make original characters.
